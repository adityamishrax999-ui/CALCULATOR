# Smart Calculator

A responsive calculator application developed as part of the Sankalp Tech Club GitHub task.

## Features

- Basic arithmetic operations
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal calculations
- Delete button
- Clear button
- Calculation history
- Persistent history
- Keyboard support
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
